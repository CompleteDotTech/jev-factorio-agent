# Retained connector snapshot qualification

`qualify_connector_snapshot_v1` supports two fixed source-built command modes.
The default `snapshot_mode="coherent"` compares connector ownership emitted by
the full factory observer with the direct ownership observer at one game tick.
`snapshot_mode="ownership-only-v1"` qualifies the direct ownership snapshot
without entering the full factory/coal observer chain. It requires the same
session and actor, installed callback identities, bridge ownership, an idle
empty connector ledger, and unchanged game tick. It changes only the bridge's
qualification metadata; it does not move the actor or pay for construction.
The direct snapshot alone does not prove the full factory observer works.

Both modes retain the existing owner lock, private attachment receipt,
checkpoint hash, one-use fixed witness path, and ambiguity/reconciliation
rules. The v1 witness stores the exact command hash. Ordinary resumed FLE
attachment accepts only the two approved command hashes generated by its
installed source for the same session and actor, then verifies the asset,
receipt, snapshot tick and snapshot digest. Arbitrary hashes and unknown modes
are rejected. Existing coherent and reviewed ownership-only v1 witnesses can
be read without rewriting them or overriding a Python command builder.

Set `JEV_NATIVE_ATTACHMENT_RECEIPT` and
`JEV_NATIVE_CONNECTOR_OBSERVER_WITNESS` to the existing private evidence when
launching a fresh resumed controller. The witness basename must remain
`native-connector-observer-v1.witness.jsonl`. Deploy and read back the reviewed
source before attachment; an older reader which supports only the coherent
command cannot validate an ownership-only witness.

Direct v1 stores snapshot metadata before printing its response. A lost reply
therefore remains ambiguous and must use `reconcile_connector_snapshot_v1`
read-only, never redispatch qualification. Reconciliation rejects unsupported
command hashes before appending a qualified event. Neither attachment nor
qualification grants gameplay acceptance or bypasses the ordinary fresh
observation, paid-action and receipt checks.
