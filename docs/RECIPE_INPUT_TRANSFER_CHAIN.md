# Current recipe-input transfer evidence

A qualified paid recipe-input transfer now includes the same enabled downstream
recipe chain used for owned raw-stock pickups. The chain binds the selected local
objective, carried products, bounded batches, machine input and in-flight work.
Current ownership, carried ingredient, machine recipe capability and burner fuel
remain required. It proves a conditional contribution along one recursive branch;
it does not prove the complete target bill or future native output.

The model consumer independently reconstructs the chain and transfer start facts
from the current catalog projection and native snapshot. Catalog recipes and
machine prototypes are copied independently of candidate annotations. Malformed,
stale or mismatched proofs receive the existing ordinary judgment instructions;
they acquire no qualified recipe-chain instruction. All native execution checks,
choice and usefulness floors, query limits and paid evaluation budgets remain.
